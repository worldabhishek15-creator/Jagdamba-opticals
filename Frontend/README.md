# Jagdamba Optical — Frontend

A responsive eyewear e-commerce frontend inspired by the supplied Jagdamba Optical reference design.

## Files
- `index.html` — page structure
- `styles.css` — responsive design
- `script.js` — product cards, search, cart counter, wishlist and newsletter interactions

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy on Vercel from GitHub
1. Create a new GitHub repository, for example `jagdamba-optical`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to Vercel and import the GitHub repository.
4. Framework Preset: **Other**
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Deploy.

No Node.js or build command is required for this version.

## Important
The image URLs currently use Unsplash images for the demo. Replace them with your own product/hero images later.

This is frontend-only. Login, admin panel, database, product management, payments and order processing are not included yet.
